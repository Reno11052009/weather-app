# Weather App

Aplikasi cuaca sederhana yang menampilkan informasi cuaca real-time untuk kota di Indonesia menggunakan OpenWeatherMap API.

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Leaflet (React Leaflet)

## Instalasi

1. Clone repository

```bash
git clone https://github.com/username/weather-app.git
cd weather-app
```

2. Install dependencies

```bash
npm install
```

3. Install Leaflet

```bash
npm install leaflet react-leaflet
npm install -D @types/leaflet
```

4. Buat file `.env.local` dan tambahkan API key OpenWeatherMap
